# Gesture Drive

Браузерная 3D-игра на React, TypeScript, Vite, Three.js и MediaPipe Hand Landmarker. Четыре полосы, бесконечная дорога, пять типов трафика, плавное управление, калибровка, интерактивное обучение, столкновения и рекорды.

## Игра в браузере через GitHub Pages

Сайт рассчитан на адрес `https://diasisenov06.github.io/CameraGame/`. Готовая статическая сборка размещается в ветке `gh-pages`.

При первом включении сайта владелец репозитория выбирает **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages → / (root) → Save**. После успешного развёртывания игру можно открыть по адресу выше. На компьютере игрока Node.js и скачивание проекта не требуются.

Для сборки сайта разработчиком: `npm run build -- --base=/CameraGame/`. Файлы из `dist`, включая локальные WASM и модель, публикуются в корне `gh-pages`; нужен файл `.nojekyll`. Пути камеры учитывают базовый адрес проекта. Обычная локальная сборка по-прежнему выполняется командой `npm run build`.

## Запуск

Нужен Node.js 22.12+ (в подготовленной среде используется Node.js 24).

**Самый простой способ на Windows:**

1. Скачайте проект с GitHub: **Code → Download ZIP**.
2. Нажмите правой кнопкой по ZIP → **«Извлечь всё»**. Откройте распакованную папку `CameraGame-main`.
3. Один раз установите **Node.js LTS** с https://nodejs.org/.
4. Дважды нажмите **`START-GAME.bat`**. При первом запуске он установит зависимости, затем откроет игру в браузере. Оставьте окно запуска открытым во время игры.
5. Нажмите **PLAY → ENABLE CAMERA**, разрешите камеру, выполните калибровку и нажмите **START RACE**. Без камеры выберите **Try keyboard mode**.

На macOS/Linux можно выполнить `sh START-GAME.sh` из папки проекта. Если зависимости уже установлены, повторный запуск не скачивает их заново. Если порт 5173 занят, запуск выберет следующий свободный порт.

В любом терминале из папки проекта также можно выполнить одну команду:

```sh
npm start
```

Обычный запуск для разработки:

```sh
npm ci
npm run dev
```

Команды выполняются из корня репозитория. Для production: `npm run build`, затем `npm run preview`, либо разместите содержимое `dist` на статическом HTTPS-хостинге. Камера работает только в безопасном контексте HTTPS или localhost. Современный Chrome / Edge рекомендован; необходим WebGL.

## Управление

- PLAY → ENABLE CAMERA → покажите руку → выполните калибровку LEFT, RIGHT, FIST → START RACE.
- Вытянутый горизонтально указательный палец: смена одной полосы. Верните руку в нейтральное положение перед следующей командой.
- Сжатый кулак: плавная остановка. Разжатая рука: ускорение. При потере руки сохраняется полоса и последнее состояние торможения.
- При первой игре пройдите интерактивное обучение. В последующих заездах оно пропускается.
- Keyboard mode: стрелки или A/D для перестроения, удержание Space для торможения. ESC — пауза. Потеря фокуса окна автоматически ставит игру на паузу.
- В главном меню и настройках TURN OFF CAMERA останавливает видеопоток. Настройки и рекорд сохраняются локально в браузере.

## Реализация

`src/game/Simulation.ts` — независимая логика скорости, полос, очков, сложности и столкновений. Трафик использует пул из 24 машин; каждый ряд оставляет две свободные полосы и появляется с запасом времени для реакции. Первые 30 секунд — один автомобиль в ряду.

`src/game/World.ts` — 3D-отрисовка, спортивный автомобиль, окружение, свет, день → закат → ночь, следы торможения, частицы, удар и тряска камеры. Окружение объединяется по материалам, дорожная разметка использует instancing, геометрия трафика переиспользуется. HIGH включает тени и увеличенное разрешение; LOW уменьшает нагрузку. 60 FPS — целевой показатель, фактическая частота зависит от GPU.

`src/handTracking/` — локальный MediaPipe и отдельные классификатор / фильтр жестов. Детекция до 25 FPS, отрисовка через requestAnimationFrame. Для подтверждения нужны большинство последних семи результатов, confidence ≥ 0.75 и стабильное направление в течение 190 мс. Cooldown 650 мс; удержание жеста не повторяет команду. Направление учитывает зеркальность предпросмотра.

`src/audio/` — синтезированный двигатель, дорожный шум, атмосферный музыкальный фон и эффекты через Web Audio, без внешних аудиофайлов.

Камера включается только по нажатию пользователя. Видео, изображения и landmarks не записываются и не отправляются на сервер. Модель, WASM и шрифты обслуживаются локально. Модель включена в `public/mediapipe`; postinstall копирует runtime из установленного пакета. Происхождение, лицензия и хеш модели описаны в `public/mediapipe/NOTICE.md`.

## Проверки

```sh
npm test
npm run build
npm run test:browser
```

Unit-тесты проверяют управление, границы дороги, торможение, потерю руки, паузу, трафик, столкновения, очки, зеркальность, стабилизацию и confidence. Браузерные тесты проверяют меню, управление, настройки, перезапуск, разрешение камеры, загрузку локального WASM/модели и остановку потока. Они используют Chromium с искусственной камерой; это не заменяет проверку реальной рукой при разном освещении.

Для браузерных тестов нужен системный Chromium по `/usr/bin/chromium`; другой путь можно задать через `CHROMIUM_PATH`. Само приложение не требует установленного Chromium на сервере.
